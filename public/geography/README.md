# Tunisia governorates — local administrative geography

`tunisia-governorates.geojson` contains 24 ADM1 features, copied from geoBoundaries gbOpen, revision `9469f09`.

- Source: **OpenStreetMap contributors / Wambacher**, distributed by **geoBoundaries / William & Mary geoLab**.

Changes: minified JSON and appended provenance metadata only. The original simplified coordinates and feature ISO identifiers are unchanged. No new administrative boundary is drawn by MASAR. This is demonstration cartography, not an official current CDIS register.

Rebuild locally with `python scripts/prepare-governorates-geometry.py`. Runtime requires no external map service, GPS or network request to these sources. The interactive view and a download link retain attribution.
